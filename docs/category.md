# 文档分类

## 应用部署

- [Casdoor](deploy_apps/casdoor.md)：身份与访问管理平台。
- [LobeHub](deploy_apps/lobechat.md)：AI 对话与知识库应用。
- [New API](deploy_apps/newapi.md)：AI 模型接口管理与分发网关。

- [ParadeDB](deploy_services/paradedb.md)：基于 PostgreSQL 的关系型数据库与检索服务。

- [RustFS](deploy_services/rustfs.md)：兼容 Amazon S3 的对象存储服务。

- [Docker 宿主机防火墙](tools/docker-setup.md)：使用本地 DOCKER-USER 规则将 Docker 发布端口接入 UFW。
